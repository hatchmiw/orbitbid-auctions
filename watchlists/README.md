# OrbitBid Watch List data

`orbitbid.json` is generated by the **Import OrbitBid Watch List** workflow from the ID-only payload produced by the root `orbitbid-watchlist-exporter.js`.

## Data boundary

The committed file contains only:

- OrbitBid internal lot IDs selected by the user;
- first/last-seen capture timestamps;
- public matches to already-saved `auctions/<id>/lots.json` records: auction ID, lot number and title;
- import counts.

It does **not** contain OrbitBid passwords, cookies, session/authentication tokens, bidder identity, max bids, auto bids, proxy bids, payment information, or scraped authenticated page text. Current public bids and bid counts remain in the existing auction metadata and `price-history.csv`.

The capture is authoritative for the current Watch List: a later import replaces membership for lots no longer present while preserving `first_seen_at` for lots that remain watched.

## Public-repository privacy

This repository is public. Importing `orbitbid.json` therefore makes the selected lot IDs and their saved-auction matches public. The browser exporter intentionally minimizes the capture to that membership information. Do not run the import workflow if Watch List membership itself should remain private.

## Capture/import

1. Sign in at `https://bid.orbitbid.com/` and open the authenticated Watch List.
2. Open browser developer tools, paste the contents of `orbitbid-watchlist-exporter.js` into the Console and run it.
3. The exporter scrolls lazy-rendered content, collects lot links, attempts same-origin pagination discovery, and creates compact `orbitbid-watchlist-v1` JSON.
4. Use **Copy JSON for GitHub Action**.
5. In GitHub, run **Actions → Import OrbitBid Watch List** and paste the JSON into `watchlist_json`.

The exporter never reads or exports card text, bidder data, cookies, local storage, session storage, or authentication headers.
